# EntityReach public MCP

This extension connects to the public, read-only EntityReach service over Streamable HTTP. No account or API key is required.

Use its three tools to read product information, find public documentation and analyse the supplied static Alphabet corporate-group sample. The sample contains 483 records across 65 country codes, including branches and locations; it does not establish 483 legal subsidiaries, current ownership or buying intent.

Public tools do not search live companies, reveal contacts, access private workspaces or start monitoring. Live company data uses a separate authenticated endpoint and requires an activated workspace, a scoped key and applicable allowances. Do not imply that installing this public extension activates live access.

Preserve coverage limitations and evidence classifications returned by the service. See https://entityreach.com/docs/mcp for connection guidance and https://entityreach.com/data-coverage for methodology.
