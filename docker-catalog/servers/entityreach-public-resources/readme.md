# EntityReach Public Resources

[Documentation](https://entityreach.com/docs/mcp)

Remote Streamable HTTP endpoint: https://entityreach.com/api/public-mcp

No authentication. Three read-only tools provide public product information, documentation resources and a supplied static corporate-group sample. This endpoint does not perform live company searches or access private workspaces. Live service access requires a separate activated workspace, scoped key and agreed allowances.
